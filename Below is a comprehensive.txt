Rather than producing a simple merged annotation table, the project culminates in the development of an **Indian Pharmacogenomic Clinical Prioritization Matrix**. # Methodology

## Overview

This study aimed to develop an **Indian Pharmacogenomic Clinical Prioritization Matrix** by integrating genomic variants from the **Genome India Project** with functional annotations from **Ensembl Variant Effect Predictor (VEP)**, pharmacogenomic information from **ClinPGx**, clinical pharmacogenomic evidence, and population allele frequency data. The overall workflow is illustrated in Figure X.

---

## 1. Genome India Project Dataset

Whole-genome variant call format (VCF) files generated by the **Genome India Project (GIP)** representing **9,768 Indian genomes** were used as the primary genomic dataset. Chromosome-wise compressed VCF files (.vcf.gz) and their corresponding index (.tbi) files aligned to the **GRCh38** reference genome were downloaded and organized for downstream analysis.

---

## 2. Genome India VCF Preprocessing

Prior to annotation, chromosome names in the Genome India VCF files were standardized to ensure compatibility with Ensembl GRCh38 reference annotations.

The preprocessing workflow included:

* Validation of chromosome-wise VCF files
* Compression using BGZF
* Index generation using Tabix
* Chromosome renaming from **chr1–chr22** to **1–22**
* Quality assessment using bcftools

The processed chromosome-wise VCF files were subsequently used for annotation.

---

## 3. Ensembl VEP Annotation

Functional annotation of all Genome India variants was performed using **Ensembl Variant Effect Predictor (VEP) version 116** in **offline mode**.

### Reference genome

GRCh38

### Annotation resources

* Ensembl Cache v116
* GRCh38 Offline Cache
* Homo sapiens primary assembly FASTA
* gnomAD
* ClinVar
* dbSNP
* COSMIC

### Computational settings

* Offline annotation
* Cache mode
* Canonical transcript annotation
* Multi-thread processing (12 CPU threads)

The following pharmacogenomically relevant annotations were extracted:

* Uploaded variation
* Genomic location
* Existing variation (dbSNP rsID)
* Variant consequence
* Variant class
* Gene symbol
* Transcript information
* Canonical transcript
* Protein consequence
* HGNC ID
* ClinVar clinical significance
* Phenotype
* gnomAD allele frequencies
* South Asian allele frequencies

---

## 4. ClinPGx Database Processing

The **ClinPGx variants database** containing **7,561 unique pharmacogenomic variants** was downloaded and processed.

The **Variant Name** column was extracted to obtain a non-redundant list of rsIDs representing clinically relevant pharmacogenomic variants.

These rsIDs served as the reference list for Genome India variant matching.

---

## 5. rsID-based Variant Matching

Annotated Genome India variants were compared against the ClinPGx rsID list using the **Existing_variation** field generated by VEP.

For each chromosome:

Genome India VEP variants

↓

Existing_variation

↓

ClinPGx Variant Name

↓

Matched variants

↓

Unmatched variants

Three datasets were generated:

* GenomeIndia_ClinPGx_Matched.tsv
* ClinPGx_NotFound.tsv
* Novel Genome India variants

---

## 6. Transcript-aware Annotation Strategy

Because a single genomic variant may affect multiple transcripts, all transcript-specific annotations generated by VEP were retained.

Each transcript was preserved independently, allowing downstream analyses to distinguish between different functional consequences across alternative transcripts.

---

## 7. Identification of Novel Genome India Variants

Variants present in the Genome India Project but absent from the ClinPGx database were classified as **novel Indian pharmacogenomic variants**.

These variants were extracted chromosome-wise as compressed VCF files.

Subsequently, transcript annotations including:

* Gene
* Transcript
* Consequence
* Variant class
* Gene symbol
* Canonical transcript

were incorporated by matching genomic coordinates with the VEP annotation files.

---

## 8. Integration of Clinical Pharmacogenomic Evidence

The **clinicalVariants.tsv** dataset containing curated pharmacogenomic evidence was integrated with the matched Genome India–ClinPGx dataset.

Two complementary integration strategies were implemented:

### rsID-level integration

Matching was performed using

Existing_variation (Genome India)

↓

Clinical variant (clinicalVariants.tsv)

### Gene-level integration

Additional annotations were obtained using

Gene Symbol

↓

Clinical Gene

The merged dataset incorporated

* Clinical evidence level
* Drug information
* Clinical phenotypes
* Pharmacogenomic response type

---

## 9. Integration of Indian Allele Frequency

Allele frequencies specific to the Indian population were extracted directly from the Genome India VCF files using genomic coordinates.

The **AF** value present within the INFO field of the original VCF files was appended as **GI_AF** to the integrated pharmacogenomic dataset.

This enabled direct comparison between

* Indian allele frequency (GI_AF)
* gnomAD Global frequency
* gnomAD South Asian frequency

---

## 10. Clinical Phenotype Filtering

Clinical phenotypes relevant to precision medicine were selected from the integrated dataset.

The selected disease categories included:

* Cancer
* Drug toxicity
* Cardiovascular diseases
* Diabetes
* Tuberculosis
* HIV infection
* Non-small cell lung cancer
* Acute lymphoblastic leukemia
* Breast cancer
* Colorectal cancer
* Pancreatic cancer
* Liver cancer
* Adverse drug reactions

Variants associated with these phenotypes were retained for downstream prioritization.

---

## 11. Development of the Indian Pharmacogenomic Clinical Prioritization Matrix

An evidence-based prioritization framework was developed by integrating:

* Genome India allele frequency
* Global allele frequency
* South Asian allele frequency
* ClinVar clinical significance
* ClinPGx annotation counts
* Clinical evidence level
* Drug association
* Disease phenotype
* Functional consequence
* Variant impact

Variants were subsequently categorized according to their clinical utility into:

* Immediate clinical implementation
* High-priority validation
* Population-specific pharmacogenomic candidates
* Research-only variants

The finalized pharmacogenomic dataset was used for:

* Allele frequency comparison (India vs Global)

* Cohort dynamics analysis
* Population divergence analysis
* ClinVar evidence classification
* Level 1A actionable pharmacogenomic variants
* Variant oncology panel generation
* Identification of clinically actionable pharmacogenes
* Development of an Indian Pharmacogenomic Clinical Prioritization Matrix
